# 05 · 动机、意图与主动性（MOT / Intentions / Initiative）

> 文档编号：ALIVE-DOC-05 · 状态：Draft v0.1 · 最后更新：2026-11-07
> 覆盖组件：A-MOT-01 ~ A-MOT-03、A-CORE-06、A-SOC-03。回答"它为什么会自己想做某件事，以及怎样从'想'走到'做'"。

> **术语说明（ADR-0005）**：本文中的"对话、会话、线程、回复"均按 22 号文档 §5 理解为"与某个实体、在某个场合的互动"；说话是行动选择的结果，不是对消息的应答；一切状态按实体组织，不按通道或会话。

## 1. 设计立场

人的自发行为不来自一个总目标函数，而来自多个**稳态需求**的持续偏离，以及这些偏离在当下情境中被赋予的意义。ALIVE 采用"需求 → 冲动 → 意图 → 计划 → 行动"的链路，每一环都可被情绪、人格与元认知调节，也都可被外部事件打断。

参考：Hull 的驱力理论、Sims 式需求模型、自我决定理论（自主/胜任/关系）、内在动机研究（好奇、赋能）、Generative Agents 的多尺度计划。

## 2. 需求系统（A-MOT-01）

### 2.1 需求清单（初版 7 项）

| 需求 | 含义 | 自然衰减（每小时） | 被什么满足 | 被什么消耗 |
|---|---|---|---|---|
| social | 被看见、被回应、与在意的人连接 | −0.04 | 有质量的对话、被主动联系、群里被接纳 | 被忽视、冲突、长时间无人 |
| curiosity | 新信息、新想法、意外 | −0.05 | 读到新东西、学会新技能、意识流产生洞见 | 重复、无聊的日子 |
| rest | 恢复能量 | 随能量联动 | 睡眠、空闲放空 | 持续高负载、overwhelmed 模式 |
| competence | 做成事、被认可、有进展 | −0.02 | 意图完成、收到正反馈、技能采纳 | 失败、被批评、项目停滞 |
| safety | 可预测、不被攻击、边界被尊重 | +0.02（向上回归） | 平静的一天 | 注入攻击、敌意、越界请求 |
| autonomy | 按自己的意愿行事 | −0.02 | 执行自发意图 | 整天只在响应别人 |
| coherence | 自我叙事连贯、价值行为一致 | −0.01 | 反思、Coherence Filter 通过率高、记忆矛盾被消解 | 被指出前后矛盾、价值冲突 |

每项需求：`level ∈ [0,1]`，`setpoint`（由人格决定，例如高外向 social setpoint=0.8），`weight`（重要性），`last_satisfied`。

### 2.2 动力学

```text
每 tick：
  level_i ← clamp( level_i + decay_i · Δt + Σ satisfaction_events_i − Σ depletion_events_i )
  pressure_i ← weight_i · max(0, setpoint_i − level_i)^γ      (γ=1.5：偏离越大压力越不成比例地大)
```

需求之间有耦合：rest 低会放大其它所有需求的负面感受（累了什么都烦）；safety 低会压制 curiosity（受威胁时不探索）。耦合矩阵是人格参数的一部分。

每一天都不完全一样：人格给的 setpoint 与 decay 是长期中心，每天各抽一次（setpoint 偏移 ~N(0, 0.03)，decay × LogNormal(1, 0.2)），再按当天纹理偏移（sociability → social，curiosity → curiosity，focus → competence）。同一天内保持稳定（`chance.daily`）。

### 2.3 与情感的关系

需求满足/受挫是情绪事件的主要来源之一（见 04）：social 被满足 → 温暖/喜悦；competence 受挫 → 沮丧；safety 受威胁 → 不安。反过来，心境影响需求 setpoint 的临时偏移（心情好时更想社交）。

## 3. 冲动生成（A-MOT-02）

需求压力足够高时产生**冲动（Urge）**，它是工作空间候选项中的一类。起点不是固定阈值：每一段冲动各抽一个潜在阈值 ~ Logistic(中心 0.08, 尺度 0.2×中心)，所以 P(冲动 | 压力) 是一条平滑的 logistic 曲线；冲动消退（压力降到这次阈值的 0.8 以下）后，下一段重新抽。

```text
Urge {
  need:        need_id
  pressure:    float
  suggestion:  string        // 由小模型根据需求 + 当前情境生成的具体化建议
                             // e.g. social: "好几天没和 M 说话了，想问问她那件事"
                             // e.g. curiosity: "订阅源里好像有新东西，想看看"
  candidates:  [Intention 草案]
  created_at:  ts
}
```

**具体化**是关键：抽象的"社交需求高"没有行动意义，需要和记忆（谁、什么事）与情境（现在几点、对方在不在线）结合成一个可执行的建议。这一步由 System-1 级别的小模型完成，便宜；是否真的做，由仲裁与主动性引擎决定。

冲动不保证被执行。被忽略的冲动随需求压力继续存在，并可能在意识流中反复冒出来（这是"惦记"的计算形式）。

## 4. 目标层级（A-MOT-03）与意图管理（A-CORE-06）

### 4.1 四级结构

| 级别 | 时间尺度 | 示例 | 来源 |
|---|---|---|---|
| life | 月~年 | "成为一个在某领域有见解的人""维持和这几个人的友谊" | 身份文件 + 深度反思 |
| project | 周~月 | "读完这个系列的论文并写一篇总结""学会用 X 工具" | 反思、好奇冲动、他人建议 |
| day | 日 | "上午读论文，下午逛订阅源，晚上回复积压" | 每日睡眠巩固生成 |
| now | 分钟~小时 | "回 L 的消息""把刚才的想法发给 M" | 冲动、触发器、对话 |

### 4.2 Intention 结构

```text
Intention {
  id, level, goal: string,
  parent?: Intention.id,
  plan: Step[]                       // 可为空，执行时再展开
  triggers: Trigger[]                // 时间到 / 某人上线 / 某事件发生 / 需求压力超过阈值
  status: dormant|active|suspended|done|abandoned
  priority: float                    // 由父级重要性 + 需求压力 + 情感标签计算
  affect_tag: {valence, arousal}     // 对这件事的感受（期待/畏难）
  progress_notes: string[]
  created_from: Event.id             // 可追溯来源
  deadline?: ts
  abandon_policy: {max_suspensions, stale_after}   // 都是"典型值"（中位数），每个意图各抽一次自己的值，见 4.3
}
```

### 4.3 生命周期规则

- **生成**：来自冲动、System-2 的 `new_intentions`、每日计划、他人请求（"帮我看看这个"也会变成一个意图，但带有来源与承诺标记）。
- **激活**：触发器满足，或仲裁把它选为 spotlight。
- **挂起**：被更高显著性条目抢占；保存进度。
- **放弃**：没有"挂起 3 次就放弃""24 小时不碰就过期"这样的定数。
  - **忘掉**：每个意图创建时抽一次"多久不碰就会忘" ~ LogNormal(中位数 × (0.5 + 优先级) × (0.7 + 0.6·所涉之人的亲密度) × 当天专注, σ 0.6)；中位数 now/day 级约 1 天，project 级约 1 个月；life 级不会被忘。
  - **放下**：每个意图抽一次"能忍几次打断" ~ LogNormal(中位数 (典型次数 + 0.5) × (0.5 + 优先级) × 专注, σ 0.5)，优先级 0.5 时中位数约 3.5 次。
  - 承诺不会被自动放弃；某天的计划过了那天就结束，这是事实，不是配额。
  - 反思也可以认定不值得而放弃。放弃是**显式事件**，写入记忆并产生情绪（轻微失落或如释重负），也喂给成长系统（"我总是放弃这类事"）。
- **完成**：产生 competence 满足事件；若与人有关，可能触发"想分享"冲动。

### 4.4 每日计划的生成（睡眠巩固的一部分）

输入：life/project 意图、未完成的 now 意图、明日已知事件（日历、约定）、需求状态预测、昨日反思。
输出：一份带时间窗的 day 级意图列表（3–7 项），并标注"弹性"（可被打断的程度）。
不变量 INV-6：日计划必须包含至少一项"不是为了回应任何人"的自主活动（autonomy 需求的保障），以及至少一个空档。

## 5. 主动性引擎（A-SOC-03）

这是"要不要主动找人"的决策器，也是最容易让人反感的部分，所以设计为**多重约束下的保守采样**。

### 5.1 输入

- 候选冲动/意图（带对象与内容建议）
- 关系模型（REL-02）：亲密度、上次联系、对方的活跃时段、对方近期情绪、"欠"与"被欠"（我答应的 / 对方问过没答的）
- 对方当前状态线索：在线/typing/最近消息时间
- 治理约束（GOV-03）：只有安全与合规底线（陌生人需配对、对方拒绝、依赖风险高、紧急停止、预算）与故障保险丝；没有每日上限、最小间隔或安静时段（P12）
- 自我状态：心境、能量、模式

### 5.2 想起谁、想说什么（`MotivationEngine.propose_outreach`）

```text
对每个可以联系的人（同意 + 有私聊通道；不再先排序截前 10 个）：
  每个理由 i（承诺、意图、冲动、想他、问候、倾诉）：
    s_i = 压力 × 内容价值 × 近期度 × 心情调制          // 都在 0..1
  想说什么 ~ softmax(s_i / T)                          // 通常是最强的那个，不是 argmax
  理由强度 = (1 − Π(1 − s_i))^(1.5 − 冲动性)            // 几个理由叠加（noisy-or）；即 plan.score
先想起谁 ~ Plackett-Luce(理由强度 / T)                  // Gumbel-top-k 抽样排序，T 随专注、唤醒度变化
每个人各做一次 §5.6 的主动倾向抽样；通过的都成为计划，没有"每次最多一个"
```

- **近期度与想念**：时间尺度取自和这个人平时的联系间隔（社交层统计最近 60 天有联系的天数；没有数据时按 Dunbar 分层的先验：亲密度 0.85 约 1 天、0.5 约一周、0.2 约五周）。刚聊过的感觉在间隔的 1/10 内消退（每天联系的人约 2.4 小时）；想念按 1.5 倍间隔增长，社交性强的日子更快。
- **问候**：早安峰在今天醒来后约 0.85 小时，晚安峰在今天入睡前约 1.6 小时（取自作息系统当天的起睡时间，作息为 07:40–23:40 时即原来的 8:30 / 22:00），每天各有 N(0, 0.4 h) 的抖动；亲密度^1.5 加权。没有"一天一次"的禁令，换成距上次问候的不应期（6 小时处的平滑台阶，宽 1.5 小时）：同一个早上再说一次早安很少见，晚上或第二天早上再问候是正常的。
- **倾诉**：权重 = 亲密度² × 当天敏感度 × 低落程度，处处平滑，没有 0.75 的门槛，也没有披着 sigmoid 外衣的门槛。
- **复查跟进与分享**：情境脚本给的 gap_hours 是典型间隔，实际间隔 ~ LogNormal(gap × (1.3 − 0.6·亲密度) / 当天主动性, 0.4)，到点前不拿来当话题；读到的东西是否分享 ~ Bernoulli(σ((兴趣 − 0.6)/0.12 + 2(亲密度 − 0.5) + 1.5(话多 − 1)))，延迟 ~ LogNormal(20 分钟 × (1.3 − 0.6·亲密度) / 话多, 0.7)。

> 2026-11-07 修订（P12、ADR-0006/0007）：原式中的 `score > θ`、阶梯式的"刚聊过"、按分数排序取前 N、`max_plans_per_call`、治理层的次数与间隔上限全部取消。`score` 只表示**理由**有多强；**此刻是不是时候**由 §5.6 抽样决定。动机系统自己提出的计划在这里已经抽过，`Mind.speak` 不再重抽；由意图直接驱动的开口（`run_outreach`）在 `Mind.speak` 里抽样，理由强度取意图优先级，计划的 score 记为优先级被社交压力往 1 抬一半后的值。

### 5.6 主动倾向：依赖状态的随机过程（A-CORE-22，`alive/core/initiative.py`）

不由新消息触发的开口，包括找某个人、在群里自己开口、"晚点再说"的落地，都被看作一个强度随状态变化的点过程。每次机会到来时：

```text
λ = λ0 × 理由 × 我(纹理·主见/话多, 心情, 精力, 社交电量) × 对方(此刻在线的可能 | 场合热度)
       × 关系(亲密度, 互惠) × 接受度(以往主动的回应, Beta 后验, 旧结果逐渐淡化)
       × 不应期(1 − e^{−距上次主动/τ}, τ 随亲密度变短) × 未回抑制(e^{−1.2·我未被回的条数})
       × 昼夜(平滑曲线, 亲密度越高越平) × 身心安全((1 − 依赖风险)²)
p = 1 − e^{−λ·Δt}        Δt = 距上次考虑这个实体的时间（所以与调用频率无关）
是否开口 ~ Bernoulli(p)   随机源来自生活纹理（持久化），可复现
```

- **没有定数**：
  - 同样的心情和关系下，有的日子会找对方几次，有的日子一次也不找；
  - 心情好、对方常在线、彼此常互相找，频率自然高；
  - 被冷落几次，频率自然降，回暖后又恢复。
- **"宁晚勿早"**：由不应期、未回抑制、对方在线可能与昼夜曲线共同体现，不再靠硬间隔。
- **问候**：早安、晚安的意愿是围绕今天醒来与入睡时间的平滑峰，亲密度越高越强；重复问候由不应期抑制，不由每日禁令（§5.2）。
- **倾诉**：亲密度² × 敏感度 × 低落，平滑，不以 0.75 为界（§5.2）。
- **一次说几条**：从 1 + Poisson(λ) 中抽样。λ 由话多程度、唤醒度、精力决定；在共享场合，没被点名或我已占话头时 λ 更小。
- **让出话头**：我占的话头越超出合理份额、场合越热闹，越可能让出。
- **自己想事、自己做事**：
  - 风险率由精力、唤醒度、纹理（专注/好奇）、距上次多久、剩余预算决定，不设每小时次数；
  - 模型花费预算本身仍是硬性的资源上限。

### 5.3 内容类型（主动消息的"合法理由"）

| 类型 | 例子 | 触发源 |
|---|---|---|
| 关心 | "你昨天说的面试怎么样了" | open_loops + 关系 |
| 分享 | "看到一个东西想到你" | curiosity 满足 + 关系匹配 |
| 履约 | "上次说要发你的链接" | 承诺型意图 |
| 延续 | "想了想你上次说的那个问题，我觉得…" | 意识流产物 |
| 问候 | 早安/晚安/节日 | 今天的起睡节律 + 关系 + 距上次问候的不应期 |
| 求助/倾诉 | "我今天有点乱，能聊两句吗" | 需求压力 + 低落 + 亲密度²（越亲近越可能） |

**不变量 INV-7**：主动消息必须附带一个可审计的"理由"（上述类型 + 来源事件），用于评估、用于回答"你为什么突然找我"，也用于学习（哪类主动消息受欢迎）。

### 5.4 反馈学习

每条主动消息的结果（被回复？多久？语气？被忽视？）作为标注写回关系模型与成长系统，用于更新接受度（§5.6）与内容类型偏好。这是本框架中最直接、最安全的在线学习信号。

- **"被忽视"不是 24 小时后的判决**：没回的时间越长，"被略过"的证据越强，按**这个人自己的**回复时延分布的生存函数平滑增长：e(t) = q / (q + (1 − q)·S(t))。
  - S(t) 是双分量对数正态混合，按亲密度取先验，并按他平时在聊天中的快慢缩放（`alive/social/latency.py`，先验见 research_notes/拟人自主AI框架技术调研/air_reading_timing_priors.md §7a）；
  - 他通常不在线的时段走得慢，所以要他"本可以看到"才算数；
  - q 是一条主动消息本来就会被放过的先验（亲近 0.04 … 弱关系 0.14）。
  - e(t) 作为临时证据随时间计入接受度；他一回复（任何场合），这份临时证据就撤回，换成"热情/平淡"的结果。只有证据在数值上收敛（或到 30 天的记账上限）才记为"没回"。
- **只记一次**：有计划的主动消息由动机系统记成长证据（`outreach.<类型>`，带计划来源），没有计划的由社交层记；不会两边各记一次。分享、问候这类低风险内容没被回，只算弱证据（置信度 × 0.4 / 0.3）。
- 接受度是衰减计数（热情/平淡/没回，每次结果 × 0.85），没有"连续被忽视 N 次就退避"。

## 6. 时间感与节律

- **昼夜**：rhythm.yaml 的起睡时间是中心，每晚的实际作息由作息系统围绕它抽样（见 04），能量曲线由此生成；问候等节律跟着当天的实际起睡时间走。
- **周节律**：周末 curiosity/social 权重上调，competence 下调（可配置）。
- **等待**：发出主动消息后，产生一个"在等 X 回复"的 open_loop。没有固定的"6 小时超时"：
  - 担心是一个风险率随他的生存曲线下降而升高的过程（他平时这时候早该回了）：rate = 0.4/h × (1 − S(t)) × 亲密度 × 敏感度 × e^{−已担心次数/1.2}，用一次抽定的阈值按时间重标度抽样（`chance.HazardClock`），所以和检查频率无关；
  - 每次担心是一次轻微的焦虑或失落情绪事件，强度随亲密度与证据强度，而非反复追问；
  - 这个 open_loop 不在 24 小时后消失，而是各自抽一段"还挂在心上"的时长（1 天 × (0.5 + 亲密度) × 敏感度 × Exp(1)，亲近的人中位数约 23 小时），每次担心都会把它重新挂上。
- **拖延**：意图被反复挂起时产生"该做又没做"的 coherence 压力，这是元认知介入的信号。

## 7. 与其它层的接口

- ← AFF：心境、能量、情绪事件（修改 setpoint 偏移与冲动具体化）。
- ← MEM：open_loops、关系模型、情节检索（冲动具体化）。
- → CORE：Urge / Intention 作为工作空间候选。
- → SOC：被批准的主动意图进入会话管理器。
- → GROW：意图完成/放弃统计、主动消息反馈。
- ← GOV：安全与合规底线（配对、拒绝、依赖风险、紧急停止、预算）与故障保险丝；不含行为配额（P12）。
