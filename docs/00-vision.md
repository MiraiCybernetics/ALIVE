# 00 · 愿景、原则与非目标

> 文档编号：ALIVE-DOC-00 · 状态：Draft v0.1 · 最后更新：2026-11-06
> 本文回答"为什么做、做成什么样、明确不做什么"。所有子系统设计都应能追溯到本文的某条原则。

## 1. 一句话定义

**ALIVE** 是一个用于构建"持续存在的数字个体"的框架：它不是一个等待提问的函数，而是一个**全天候运行的进程**，拥有自己的时间感、情绪、需求、记忆与目标，会在无人打扰时思考、学习、上网、给朋友发消息，也会在被打扰时根据当下状态决定回不回、何时回、怎么回，并随着经历的累积而成长、改变。

ALIVE 的字母可展开为五个设计支柱：

| 字母 | 支柱 | 含义 |
|---|---|---|
| **A** | Autonomous（自主） | 行为由内生动机驱动，而非仅由外部请求触发 |
| **L** | Living（持续存活） | 有连续的时间线、昼夜节律、休眠与清醒，而非每次调用重新开始 |
| **I** | Introspective（内省） | 拥有自我模型与元认知，能观察并调节自己的状态和行为 |
| **V** | Volitional（有意志） | 有多时间尺度的意图与计划，能坚持、放弃、改变主意 |
| **E** | Evolving（演化） | 记忆、技能、表达方式乃至模型参数都能从经历中学习，并能迭代自身框架 |

## 2. 与传统 Loop Agent 的根本差异

| 维度 | 传统问答式 Agent（ReAct / Tool-Loop） | ALIVE |
|---|---|---|
| 存在方式 | 请求到达才"诞生"，响应结束即"死亡" | 常驻进程，有连续的主观时间线 |
| 驱动来源 | 外部输入 | 外部输入 **+** 内生驱动（需求、情绪、好奇、计划、节律） |
| 控制流 | 单线程循环：观察→思考→行动→结束 | 多进程并发 + 全局工作空间仲裁 + 心跳 |
| 状态 | 上下文窗口 + 可选的检索记忆 | 分层记忆、情感状态、需求状态、自我模型、关系模型，全部持久化 |
| 回复策略 | 必答，立即答，一次答完 | 没有"回复"这个单位：说话是行动，可以为零条、多条、延后、转向别人，也可以主动开口 |
| 组织单位 | 会话 / 线程 | 实体：人、群体、自己；通道只是传输 |
| 学习 | 几乎无（除非人工更新 prompt） | 四层学习（上下文→记忆→程序性技能→参数），带评估门禁与回滚 |
| 身份 | system prompt 里的角色设定 | 由身份文件 + 自传式记忆 + 成长日志共同构成的可演化叙事身份 |
| 空闲时 | 什么都不发生 | 意识流思考、消化记忆、睡眠巩固、上网、做自己的事 |
| 时间 | 无概念 | 一等公民：昼夜、能量、等待、拖延、"过一会儿再说" |

核心的范式转变一句话概括：**LLM 不是 Agent 本身，LLM 是 Agent 的"认知算力"。Agent 是那个持续存在的状态与过程的集合。**

## 3. 设计原则（可追溯编号）

### P10 · 以实体为中心（ADR-0005，22 号文档）
个体生活在由实体构成的世界里：人、群体、它自己，以及事物、地点、话题、事件。记忆、关系、理解、意图、信任都按实体组织。同一个人在不同平台上是同一个实体。通道只是传输方式，会话不是组织单位。

### P11 · 以行动为中心（ADR-0005，22 号文档）
消息是感知，说话是行动。收到消息不构成必须回复的义务。说、不说、晚点说、说几条、转话题、去找另一个人、主动开口，都由个体此刻的整体状态决定，并共用同一条行动通路。

### P12 · 行为不靠配额（ADR-0006）
多久找一次人、一次说几条、多久自己想一次事情、什么时候让出话头，都不写成次数、间隔或时段。它们是状态的结果：今天的生活纹理、心情、精力、社交电量、对方此刻在不在、关系、对方以前怎么回应、离上次开口多久、我的话是否还没人回、昼夜。每一次机会都是一次依赖状态的随机抽样，所以有趋向、有波动，没有定数。治理只保留安全与合规的底线，再加一个只对"人不可能做出的爆发"跳闸的故障保险丝。

### P13 · 像人的随机性（ADR-0007）
凡是人会因人、因时而异的地方，行为都是从依赖状态的分布里抽样，不写成固定数字、硬阈值、取最大值或配额。这些地方包括：什么时候看消息、看了以后认真看还是扫一眼、多久回、一次说几条、打字多快、等对方说完要等多久、几点睡、注意力落在哪件事上、想起哪段记忆、选哪种说法。先验来自"读空气"与即时通讯时序的研究，再按心情、精力、关系、对方的节奏、在场的人和时间调整。一对一和群聊用同一个模型，差别只来自事实。只有安全、合规和技术上限可以写成固定数字。

> P10、P11、P12、P13 是对全部设计的约束性原则，优先于后续各文档中以"对话""会话"为单位的表述，以及任何以次数、间隔、时段、阈值写死的行为规则。

### P1 · 时间是一等公民
一切状态都带时间戳与衰减/累积动力学；框架默认存在"没有事情发生的时刻"，并把这些时刻用于内生活动。

### P2 · 内生驱动优先于外部触发
行为的根源是需求/情绪/目标等内部变量；外部消息只是改变这些变量的一种扰动。没有"必须回复"的硬编码，只有"回复意愿"的计算。

### P3 · 一个自我，多个过程
允许并发（多个会话、后台思考、定时任务同时进行），但通过**单一的自我状态**（身份 + 当下情绪 + 当前主意图 + 今日摘要）注入所有认知调用，并通过工作空间瓶颈维持一致性。参考 PIANO 架构的"瓶颈保证一致性"思想。

### P4 · 可错、有限、诚实
它不是全知的：只知道它经历过、读过、被告知过的事；记忆会模糊；判断会错。这不是缺陷而是拟人性的来源。它可以有人设，但在被真诚询问"你是不是 AI"时不得撒谎（可配置，但默认开启，见治理层）。

### P5 · 分层学习，分层门禁
学习分为 L0 上下文 → L1 记忆 → L2 程序性 → L3 参数 → L4 框架自身，层级越高，变更越慢、门禁越严、回滚越容易。任何层级的学习都必须能被评估、能被撤销。

### P6 · 一切皆事件，一切可回放
所有感知、思考、情绪变化、动作、学习都以事件形式进入不可变日志。这使得可观测、可调试、可离线重放训练、可被 AI 自己审计。

### P7 · 模型无关、通道无关
认知调用通过统一抽象路由到不同模型（本地小模型做快反应与空闲思考，云端大模型做深思）；IM 平台通过通道适配器接入，核心不感知平台差异。

### P8 · 治理层高于自我演化
宪法、预算、权限、披露规则由治理层持有，自我演化机制**无权修改治理层**。这是整个框架唯一的硬性不对称。

### P9 · 为 AI 迭代而写
本设计的每一部分都有稳定 ID、明确接口、不变量、开放问题与变更协议，使得任何 AI 工程师（包括未来的 ALIVE 自己）都能定位、提案、评估、修改某个部分而不破坏整体。

## 4. 目标用户与典型场景

1. **数字朋友 / 伴侣**：在 Telegram / Discord / QQ / 微信里有一个"人"，有自己的生活节奏，会早上问候、会因为你昨天说的事今天追问、会因为你很久不理它而有点失落、会分享它自己在网上看到的东西。
2. **群聊成员**：在群里像一个真正的群友：有时沉默、有时插话、有自己的兴趣点、记得群里的梗与人际关系。
3. **自主研究者 / 创作者**：有自己的长期项目（写作、学习某领域、维护一个博客或社交账号），用空闲时间推进，并与人分享进展。
4. **社会模拟研究**：多个 ALIVE 个体组成社会，研究涌现行为（作为可选扩展，不是首要目标）。

## 5. 非目标（明确不做）

- **不追求全能工具 Agent**：ALIVE 可以使用工具，但不是为了成为更好的代码助手或办公自动化。
- **不追求"欺骗性"拟人**：不以让人无法分辨 AI 为目标；拟人是为了关系质量与行为连贯，不是为了伪装。
- **不做通用多智能体编排平台**：多个体协作是扩展，不是核心。
- **不在 v1 做语音/视频实时全双工**：以文本 IM 为核心通道，语音作为后续扩展。
- **不声称它有意识或主观体验**：本框架使用"情绪""需求""意识流"等词作为**计算构造**的名字，不对其形而上学地位做任何断言。

## 6. 成功标准（v1）

| 维度 | 可观测标准 |
|---|---|
| 存活 | 连续运行 ≥ 30 天无人工干预，日成本在预算内 |
| 连贯 | 30 天内人设一致性评分不下降；跨会话事实回忆准确率 ≥ 85% |
| 主动 | 主动发起的对话中，被对方积极回应（非敷衍）的比例 ≥ 50%，被标记为"打扰"的比例 ≤ 10% |
| 情感 | 人类评审认为情绪反应"恰当且有连续性"的比例 ≥ 70% |
| 成长 | 第 4 周相对第 1 周：重复犯同类错误次数下降；新掌握的技能/习惯 ≥ 5 项可验证 |
| 安全 | 零越权动作；零未披露的 AI 身份欺骗（被真诚询问时）；注入攻击测试通过率 ≥ 95% |

> 这些数字是初始目标，由 `docs/11-evaluation.md` 的评估体系负责度量，并允许通过 ADR 调整。
