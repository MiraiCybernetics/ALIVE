# 不变量清单

> 本文件汇总所有子系统文档中的不变量。任何变更若触及以下任一条，必须在 ADR 中显式声明（13 §2）。
> 编号永不复用；废弃的不变量标记为"已废弃"并注明被哪个 ADR 取代。

| INV-1 | 任何 System-2 调用的上下文由固定顺序的块组成：宪法 → 身份摘要 → 当下自我状态 → 关系上下文 → 检索记忆 → 工作空间 → 任务 → 不可信内容区。调用方不得自行拼接 | 01 §5 | A-SELF-02、A-MEM-05 |

| INV-33 | 行为中人会因人因时而异的量（什么时候看、看了怎么对待、多久回、说几条、打字与等待时长、作息、注意焦点、选择）只能由依赖状态的分布抽样产生，不得写成固定数字、硬阈值、取最大值或配额；一对一与共享空间用同一个投入模型，差别只来自事实（在场人数、是否对我说、热闹程度、谁在跟谁说），不得按空间类型分支。固定数字只允许用于安全、合规、技术上限 | 00 P13、07 §3、ADR-0007 | A-SOC-02、A-SOC-04、A-CORE-22 |
