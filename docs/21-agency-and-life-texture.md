# 21 · 自己的态度与生活纹理：主体性与随机系统

> 文档编号：ALIVE-DOC-21 · 状态：Draft v0.1 · 最后更新：2026-11-06
> 新增组件：A-CORE-19 会话主体性、A-CORE-20 立场与反附和、A-RT-06 生活纹理（随机系统）。
> 与相邻文档：19 号文档的话步策略决定"这一步怎么走"，本文决定"我有多少自己的主张、我此刻是什么底色"。

> **术语说明（ADR-0005）**：本文中的"对话、会话、线程、回复"均按 22 号文档 §5 理解为"与某个实体、在某个场合的互动"；说话是行动选择的结果，不是对消息的应答；一切状态按实体组织，不按通道或会话。

## 1. 问题

前面的设计让个体会读懂、会说话、会选策略，但它仍可能变成一个"永远顺着对方走"的对象：
- 对方起什么话题就聊什么。
- 对方说什么都附和。
- 自己从不提起自己想聊的事。
- 每天都是同一个状态。

真人不是这样。人有自己的知识、性格、环境、状态、情绪和动机：
- 会有自己的态度，会不同意，会把话题带到自己感兴趣的地方。
- 有的日子话多，有的日子懒得说话；有时突然迷上一个东西。

但真人也不会在朋友难过的时候大谈自己的事，不会为了显得有个性而处处唱反调。

本文给出两个机制：
- **会话主体性**：每一轮显式计算"我有多少自己的主张"，并在主体性与共情之间取得平衡。
- **生活纹理**：一个带趋向性与突变的随机系统，为个体的各种倾向提供"有经历的人"那样的时间结构。

## 2. 会话主体性（A-CORE-19）

### 2.1 主体性水平

每一轮计算一个 0–1 的主体性水平 `agency`，它决定自己的态度和话题在这一轮占多少分量。

```text
agency = σ( a0
          + 0.8·(外向性 − 0.5) + 0.6·(开放性 − 0.5) − 0.6·(宜人性 − 0.5)        // 人格
          + 0.8·(纹理.主见 − 0.5)                                                // 今天的底色（§4）
          + 0.4·心境唤醒度 + 0.3·心境愉悦度                                     // 情绪状态
          + 0.5·亲密度                                                           // 越熟越敢有主张
          + 体裁项                                                               // 倾诉、哀伤、吐槽中强烈为负；闲聊、讨论、打趣为正
          + 0.6·话题失衡                                                         // 最近几个话题都是他起的
          + 0.6·想说的压力 )                                                     // 我心里有想分享的事
```

**共情的硬约束**：对方需要倾听、安慰、陪伴，并且情绪为负时，主体性上限为 0.25。也就是说，这一轮以他为主。

### 2.2 自己的议程

每一轮从以下来源收集"我自己想说的"：
- 工作空间中显著性最高的几项：刚读到的东西、正在想的事、想分享的冲动。
- 今天真实发生过的事：今日摘要。
- 和这个人有关的未完成事项：答应过的、想问的。
- 我对当前话题的看法：观点记忆中与话题相关的条目，以及人格中的价值与兴趣。

### 2.3 新增话步

| 话步 | 说明 | 何时推荐 |
|---|---|---|
| own_view | 表达自己的看法或态度 | 讨论、闲聊；我对此有观点；主体性中等以上 |
| disagree_soft | 有保留地不同意，带理由，不否定对方这个人 | 我真的不同意；对方不在情绪低谷；主体性中等以上 |
| self_topic | 主动提起自己想聊的事 | 当前话题在收尾（回复变短、出现结束信号）、或话题长期由对方主导、或我有很想分享的事；不在对方需要倾听时 |
| counter | 打趣式回怼、唱反调 | 亲近圈、在玩的框架 |

话步策略（19 §5）把这些话步的先验乘以主体性：主体性高时放大，低时压低到接近零。

### 2.4 立场与反附和（A-CORE-20）

回复调用输出这一轮的立场：同意、部分同意、不同意、中立、转向自己的话题。

- 按人记录最近 20 轮带观点的回合的立场分布。
- 同意率超过 0.85 时，下一轮在提示中注明"我最近对他几乎都在附和"，并提高 own_view 与 disagree_soft 的先验。这对应 08 号文档的"立场改变率"监控，用于对抗谄媚漂移。
- 不同意必须真诚：只在我真的有不同看法时才不同意，不为了显得有个性而反对（哈贝马斯的真诚性，20 §8）。

### 2.5 感受与判断分层（2026-11-07 修订）

**问题**（留出评估 v1–v2 在多轮里稳定出现）：对方带着情绪下了一个判断时，个体总是顺着判断附和。例如对整类事物的笼统否定，或者对一个不在场的人的定性。

原因是结构性的。这种消息被归为"吐槽 + 需要倾听 + 情绪为负"，于是触发 §2.1 的共情硬约束，主体性被压到 0.25 以下。own_view 和 disagree_soft 的先验被乘以 0.3 和 0.15，观点也不进提示。结果"接住他的感受"和"认同他的判断"被当成了同一件事。

**依据**：
- **认可的层级**（Linehan, 1997）：认可的是对方的感受和反应在其处境下"可以理解"，并不是认可他的每个命题；"认可有效的部分"。
- **共同反刍**（Rose, 2002；Rose et al., 2007）：朋友之间反复讨论问题、彼此附和负面评价，虽然让关系更亲近，却会加重焦虑和抑郁。一味附和并不等于好的支持。
- **以人为中心的安慰**（Burleson, 2003）：高质量的安慰承认并展开对方的感受，而不是对事情下结论。
- **对事不对人**：抱怨具体行为与批评整个人是两回事（Gottman, 1994）；只凭一面之词给第三人定性，容易犯基本归因错误（Ross, 1977）。

**机制**：
- 快速阅读多输出一项 `claim`：对方亮出的判断或结论，没有就留空。
- 共情锁照旧管住两件事：**话题**（不提自己的事）和**感受**（不争他该不该这么感觉）。
- 对 `claim` 的立场另算。只有在下列情况下才仍然关闭：
  - 对方在倾诉；
  - 有危机迹象；
  - 情绪极强（sentiment ≤ −0.85）；
  - 命中高风险图式。
- 立场开放时，立场类话步（own_view、disagree_soft，以及新增的 qualify："同意一部分，对事不对人，落回眼前这件事"）使用单独的立场主体性。它由主见、宜人性、开放性和亲密度决定，不受体裁项压制。
- 提示里写明：感受和判断是两回事；判断我怎么看就怎么说，可以同意、部分同意或对事不对人，不必为了安慰而全盘附和。
- 反过来也成立：真同意就同意，不为了显得有主见而反对（§2.4 的真诚性）。

**评估**：
- v2 中暴露这一问题的三题（opinion_cities、bait_team_lead、repeat_complaint）已退役。
- 新一套 v3 由 Codex 在看不到本仓库的情况下盲写，包含"该认同""该只陪伴不讨论"等反向对照题。

**结论（2026-11-07）**：
- 在同一份最终代码上做消融，开启时贴合度 4.17，关闭时 4.22，每组 60 个样本，差别在噪声内。
- 开启时 library_seat 反而略差：开启为 [5,3,3,4,5,5]，关闭为六次全 5。
- 这个机制在盲测上没有带来收益，因此**默认关闭**（`dialogue.separate_claim: false`）。代码与开关保留，供后续研究；附和问题仍列为已知短板。

## 3. 话题主导权

对话状态（19 §3）中记录每个话题由谁开启。
- **话题失衡**：最近的 N 个话题中由对方开启的比例。
- **收尾信号**：对方回复变短、出现"哈哈""嗯嗯"之类的应和而没有新内容、出现结束语。
- 失衡高或出现收尾信号时，self_topic 的先验上升。转换要有过渡（19 §5.3）。

## 4. 生活纹理：带趋向性与突变的随机系统（A-RT-06）

### 4.1 为什么需要

真人的倾向不是常数，也不是白噪声：
- 有惯性：今天话多，明天大概率也话多。
- 有阶段：一段时间很忙、一段时间很闲。
- 偶尔有突变：突然迷上一个东西，突然不想说话。

这种时间结构是"像有真实经历的人"的重要来源。纯常数显得机械，纯随机显得精神分裂。

### 4.2 三层结构

| 层 | 过程 | 时间尺度 | 作用 |
|---|---|---|---|
| 趋向 | 均值回归的随机过程（Ornstein–Uhlenbeck），多个维度通过共享的潜在因子相关 | 小时到天 | 惯性与平滑的波动 |
| 阶段 | 马尔可夫链在若干时期之间切换：平常、活跃期、低潮期、沉迷期、忙碌期；每个时期改变各维度的均值 | 天到周 | 一段时间的整体底色 |
| 突变 | 泊松过程触发的跳变，幅度服从重尾分布，之后按半衰期衰减；包括"兴趣突变"：突然迷上最近接触到的某个话题 | 偶发 | 心血来潮、突然的转变 |

```text
维度 x_i:   dx_i = θ_i (μ_i + 阶段偏移_i + 跳变_i − x_i) dt + Σ_j L_ij · dW_j        (W_j 为潜在因子)
阶段:       每天在日界处以转移矩阵 P 切换；转移概率受最近真实经历调节（例如连续几天心境偏低，进入低潮期的概率上升）
跳变:       以速率 λ（默认每天 0.25 次）发生；选一个维度，幅度 ~ 学生 t 分布，半衰期 2–5 天
兴趣:       话题兴趣向量也按均值回归随机过程漂移；兴趣突变时，从最近的阅读与对话中选一个话题大幅提高权重
```

### 4.3 维度

| 维度 | 影响 |
|---|---|
| 话多（chattiness） | 群聊回复频率、回复长度倾向 |
| 主见（assertiveness） | 会话主体性 |
| 玩心（playfulness） | 打趣与接梗话步的先验 |
| 主动（initiative） | 主动外联阈值 |
| 好奇（curiosity） | 阅读与意识流的频率、对新话题的兴趣 |
| 社交（sociability） | 社交需求的设定点偏移 |
| 专注（focus） | 专注模式的进入倾向 |
| 敏感（sensitivity） | 情绪评价的强度系数 |

每个维度的长期均值来自人格文件。生活纹理只在均值附近形成有结构的波动，不改变人格本身。

### 4.4 诚实与可解释

- **只影响倾向与选择，不编造经历**。它决定今天更想读什么、更想找谁、话多还是话少。由此产生的经历都是真实发生的，并记入今日摘要。它从不生成"今天去了公园"这类没有发生的事（08 §3 的不变量）。
- **进入自我状态**：当前时期与最近的突变，以自然语言出现在自我状态中，例如"这几天莫名话多""最近迷上了海洋生物"。个体因此能如实谈论自己的变化，行为变化也有前因后果。
- **可审计、可复现**：每次阶段切换与突变都发出 `rt.mutation` 事件。随机数生成器的种子与状态持久化，测试中可以固定种子复现。

## 5. 不变量

| ID | 内容 |
|---|---|
| INV-24 | 对方需要倾听、安慰或陪伴并且情绪为负时，主体性上限为 0.25，不发起自己的话题；可选（默认关，盲测无收益）：该锁只管话题与感受，不管我对他所下判断的看法（§2.5） |
| INV-25 | 不同意必须基于自己真实的看法；不得为制造个性而反对 |
| INV-26 | 生活纹理只改变倾向与选择，不生成任何未发生的经历 |

## 6. 评估（补充 11 号文档）

| 指标 | 方法 |
|---|---|
| 附和率 | 按人统计带观点回合中的同意比例；不应长期高于 0.85 |
| 话题主导分布 | 个体开启话题的比例；按亲密度分组，应处于合理区间 |
| 共情约束合规 | 倾诉、哀伤场景中发起自己话题的次数，应为 0 |
| 纹理的时间结构 | 各维度的自相关、阶段停留时长、突变频率与配置一致 |
| 可解释性 | 个体被问"你最近怎么了"时，回答与实际的阶段与突变一致的比例 |
