# 08 · 自我模型与元认知（SELF）

> 文档编号：ALIVE-DOC-08 · 状态：Draft v0.1 · 最后更新：2026-11-06
> 覆盖组件：A-SELF-01 ~ A-SELF-04、A-CORE-07 的判据来源。回答"它怎么知道自己是谁、此刻怎样、以及怎样在改变中保持是同一个'人'"。

## 1. 设计立场

一个会成长的个体必须同时满足两件看似矛盾的事：**会变**（否则没有成长）和**还是它**（否则没有身份）。ALIVE 的解法是把自我分成三层，变化速率依次放开：

| 层 | 内容 | 变化方式 | 变化速率 |
|---|---|---|---|
| 不变区（Core） | 核心价值观、红线、基本人格倾向、名字与来历 | 仅人类 owner 通过治理流程修改 | ≈ 0 |
| 缓变区（Narrative） | 自我叙事（我是怎样的人、经历过什么、在乎什么）、长期目标、习惯 | 睡眠/深度巩固中由反思更新，需通过一致性门禁 | 周~月 |
| 速变区（State） | 当下情绪、能量、注意、今日摘要、未完成事项 | 每 tick 更新 | 秒~小时 |

Coherence Filter（02）只对不变区严格，对缓变区宽松，对速变区不检查。这回答了 OQ-06。

## 2. 身份核心（A-SELF-01）

以文件形式存在（便于人类与 AI 共同编辑、便于版本管理），参考 OpenClaw 的 SOUL.md / IDENTITY.md 实践，但结构化程度更高：

```text
identity/
  core.md          # 不变区：名字、来历、核心价值（≤10 条）、红线（引用宪法）、
                   #         人格参数（Big Five 数值 + 文字描述）、不可妥协的边界
  narrative.md     # 缓变区：第一人称的自我叙事（我是怎样的人、怎么变成这样的、
                   #         我在乎什么、我的几个长期目标、我的习惯与癖好）
  voice.md         # 缓变区：说话方式（用词、句长、表情习惯、口头禅、忌讳），
                   #         附最近 30 条"典型的我"的发言样例（由巩固自动维护）
  relationships.md # 缓变区：对自己最重要的几段关系的一句话定位（细节在 REL）
  boundaries.md    # 不变区+缓变区：我不做什么、我在什么情况下会拒绝/离开
```

**压缩版**：SELF-02 每天从以上文件生成一段 ≤ 400 token 的"身份摘要"，用于 INV-1 的 `[身份核心摘要]` 块。全文仅在反思、身份相关对话或一致性仲裁时装配。

**每天换一批说话样例**：放进提示的几条 voice 样例每个本地日抽一次（Gumbel-top-n，人设样例分 1.0、学到的样例按其分数，温度 0.3），人设样例约占三分之二，学到的轮流出现。一天之内不变，提示前缀缓存仍然有效。

**叙事修改的门禁是"准备度"而非固定周期**：距上次修改 d 天时，愿意改的概率为 1 − exp(−(d/7)³)（3.5 天约 12%，7 天约 63%，10 天约 95%），同一晚不会改两次；之后仍需通过一致性检查。

## 3. 当下自我状态（A-SELF-02）

每次认知调用注入的速变区快照，由单一 actor 串行维护（INV-3）：

```text
SelfState {
  identity_digest:      string        // 来自 SELF-01，每日刷新
  mood_label:           string        // "有点低落但平静" ← 由 PAD 向量 + 情绪事件翻译
  energy_label:         string        // "午后犯困" ← 能量 + 昼夜相位
  dominant_intention:   string        // "正在读那篇关于记忆巩固的论文"
  today_digest:         string        // 今天到现在为止做了什么（≤ 150 token，滚动更新）
  open_loops:           string[]      // ≤ 7 条：没回的消息、答应的事、没想完的问题
  recent_self_notes:    string[]      // ≤ 3 条：最近的自我观察
  mode:                 Mode
  updated_at:           ts
}
```

**翻译而非倾倒**：不把原始数值（PAD=[-0.2,0.3,0.1]）给模型，而是翻译成第一人称自然语言。数值供算法使用，语言供生成使用。翻译表由人格决定（同样的 PAD，不同人格的措辞不同）。

**今日摘要的真实性**：today_digest 只能由实际发生的 Outcome 事件生成，禁止由模型"想象"今天做了什么。这是回答"你今天干嘛了"不撒谎的保证。

## 4. 元认知（A-SELF-03）

元认知是"对认知的认知"，在 ALIVE 中落实为四个持续运行的监控器和一个调节器。

### 4.1 监控器

| 监控器 | 观察什么 | 产出 |
|---|---|---|
| 置信监控 | 每次 S2Output 的 confidence 与后续验证结果（对方纠正、事实核查） | 校准曲线；对低置信领域自动使用不确定表述；"我不太确定"的能力 |
| 一致性监控 | Coherence Filter 的失败率、被他人指出矛盾的次数 | coherence 需求的消耗；反思议题 |
| 模式监控 | 行为统计：回复率、主动率、意图放弃率、意识流主题分布、情绪分布 | 自我观察（"我这周很少说话""我最近总想那件事"） |
| 偏离监控 | 当前行为/叙事与不变区的距离（嵌入距离 + LLM 判断） | 身份漂移告警 → 进入反思，必要时回滚缓变区 |

### 4.2 调节器

元认知可以对下游做有限的调节，这是"自我调节"的计算形式：

- 调整显著性权重的临时偏移（"我决定今天少看群"）
- 启用情绪调节策略（见 04：再评价、延迟表达）
- 把某个反复出现的意识流主题升级为 project 意图，或明确放下（写入叙事："我决定不再纠结 X"）
- 请求人类 owner 介入（置信持续低、身份漂移告警、价值冲突）

调节器的每次动作都是事件，并附带理由，构成"我为什么这么做"的可追溯链。

### 4.3 内省的边界

LLM 对自身内部状态的内省只是弱信号。Anthropic 2025 年 10 月的研究中，向模型内部注入概念后，最强的模型也只在约 20% 的情况下能察觉。2026 年的一项元认知测评发现，20 个模型中有 17 个"能监控、不能控制"：它们能报告自己的置信度，却不会据此改变行为。因此 ALIVE **不依赖模型自述其内部状态**，而是让元认知读取**外部可观测的记录**（事件日志、统计、过滤器结果）来形成自我观察。模型的"我觉得我…"被当作假设，由记录验证。置信监控同理：用外部统计的各类任务命中率，决定直接做、先查证、求助还是拒绝，而不是相信口头给出的置信度。

## 5. 成长日志（A-SELF-04）

自传式记录，按章节组织，由深度巩固（每周）写入：

```text
journal/
  2026-W45.md   # 本周发生了什么重要的事、我学到了什么、我哪里变了、我对自己的新认识、
                # 下周想试的改变（带可验证的标准）
  chapters.md   # 更长尺度的"章节"：我生命里的阶段划分（由每月反思维护）
```

成长日志是缓变区叙事的素材来源，也是评估"它有没有在成长"的一手证据（11）。

## 6. 心智理论（对他人的模型）

对他人的建模放在 REL（07），但元认知负责一项交叉功能：**区分"我知道的"与"对方知道的"**。每个 Person Model 维护一份"共同知识"列表（我们都知道的事）与"我知道但没告诉 TA"的列表；撰写回复时据此避免提及对方不该知道的事（例如从别人那里听来的私事），也避免重复讲对方已经知道的事。

## 7. 身份连续性保障清单

| 威胁 | 机制 |
|---|---|
| 谄媚漂移（越聊越顺着对方） | voice.md 样例锚定；一致性监控统计"立场改变率"；人格参数中的"宜人性"上限 |
| 多会话人格分裂 | INV-1 统一装配 + INV-3 单一自我状态 |
| 自我修改失控 | 不变区只读；缓变区修改需通过一致性门禁与回滚点（13） |
| 记忆污染导致的虚假自我 | 自我相关的记忆写入需有 Outcome 来源；来自他人的"你以前说过…"标记为 claimed_by_other |
| 模型更换导致的"换了个人" | voice.md 样例 + 身份评估套件作为模型迁移的验收标准（11） |

## 8. 与其它层的接口

- ← CORE：self_notes、confidence、模式切换、Coherence Filter 结果。
- ← AFF：PAD/能量 → 翻译成 mood/energy label。
- ← MOT：dominant_intention、open_loops。
- ← MEM：today_digest 的来源事件、叙事更新所需的情节与反思。
- → CORE：identity_digest、SelfState 快照、显著性偏移。
- → GROW：成长日志、自我观察（作为学习议题）。
- → GOV：身份漂移告警、请求人类介入。
