# 14 · 路线图与里程碑

> 文档编号：ALIVE-DOC-14 · 状态：Draft v0.1 · 最后更新：2026-11-06
> 每个里程碑都给出"能演示什么"和"用什么指标验收"。顺序按依赖关系排，不按难度。

## M0 · 骨架：会记事的回声（2–3 周）

- 事件总线、存储、Clock（含模拟时间）、Model Router（fast / deliberate 两档）。
- 一个通道适配器（推荐 Telegram 或 OneBot，调试方便）。
- 最小上下文装配（INV-1 的固定块顺序，内容可以先很简陋）。
- 情节记忆写入 + 简单检索。
- **演示**：能聊天，第二天还记得昨天聊过什么；内省面板能看到每次调用的装配内容。
- **验收**：重建一致率 100%；跨日事实回忆 ≥ 70%。

## M1 · 有自己的节奏（3–4 周）

- 回复意愿、debounce 合并、分段、typing 延迟（07）。
- 情感最小集：心境 PAD + 情绪事件 + 能量与昼夜（04）。
- 自我状态与今日摘要（08 §3）。
- 睡眠窗口与最简睡眠巩固（会话摘要 + 事实抽取 + 明日计划）。
- **演示**：它晚上会"困"，深夜消息早上才回，并且会提到"昨晚看到你消息了"。群里不再每条都回。
- **验收**：群聊发言占比落在配置区间、不在别人拆句中间插话；人类评审"节奏像人"≥ 60%。

## M2 · 无人时也活着（4 周）

- 需求系统 + 冲动生成 + 意图管理（05）。
- 意识流（02 §6）。
- 主动性引擎 + 治理侧主动上限（05 §5、09）。
- Web 阅读（订阅源 + 网页抓取），不可信内容隔离（09）。
- **演示**：一整天没人理它，它读了几篇东西，记了笔记，下午主动给一个朋友分享了其中一篇，理由可追溯。
- **验收**：主动消息积极回应率 ≥ 40%；打扰标记率 ≤ 15%；注入测试集拦截率 ≥ 90%。

## M3 · 会成长（4–6 周）

- 完整记忆系统：语义/关系/程序性存储、多因子检索、遗忘、矛盾消解（03）。
- 反思与技能习得（L0–L2 学习，06），带评估门禁与回滚。
- 表达学习（从群聊中学习说话方式）。
- 元认知监控器（08 §4）。
- 成长日志。
- **演示**：第 4 周比第 1 周少犯同类错误；学会了一个群里的梗并在合适时机用上；能说出"我这周学到了什么"并且有证据。
- **验收**：11 的成长指标显著为正；人设一致性不下降。

## M4 · 评估与模拟器（与 M2–M3 并行）

- Life Simulator：合成联系人（由 LLM 扮演的不同性格的人）、加速时间、可复现种子。
- 冻结回归集 + 私有考题机制。
- **演示**：30 天的生活在 2 小时内跑完，产出一份评估报告。

## M5 · 参数层学习（可选，6 周+）

- 个体专属适配器：从睡眠巩固产出的训练样本（自己的优质发言、纠正过的错误）做周期性微调。
- 适配器版本管理、A/B、回滚（06 L3）。
- **验收**：语音一致性与事实回忆在适配器上优于纯检索基线，且通用能力回归 ≤ 2%。

## M6 · 框架自迭代（持续）

- 个体 S1 级提案（13 §6）。
- 外部编码代理按 ADR 流程迭代框架。

## 风险登记

| 风险 | 可能性 | 影响 | 缓解 |
|---|---|---|---|
| 成本失控（意识流、巩固调用过多） | 高 | 高 | 预算硬上限 + 本地小模型承担 fast/意识流 + 成本账本日报 |
| 主动消息让人反感 | 中 | 高 | 依赖状态的主动倾向过程（没有配额，ADR-0006/0007）、对方反应的后验、反馈学习、一键"少找我"、故障保险丝 |
| 人设漂移 | 中 | 高 | 不变区只读、voice 样例锚定、漂移监控 + 回滚 |
| 记忆污染（错误事实被反复强化） | 中 | 中 | 来源与可信度标记、矛盾消解、"他人声称"标签 |
| 注入攻击经网页/群聊进入 | 高 | 高 | 可信等级隔离、不可信内容不进指令区、副作用动作需可信触发 |
| 用户过度依赖 | 中 | 高 | 09 的依赖信号监测、时长提醒（合规要求）、不阻拦退出 |
| 合规（AI 身份披露、数据使用） | 中 | 高 | 09 的披露策略与数据同意流程，按部署地区配置 |
