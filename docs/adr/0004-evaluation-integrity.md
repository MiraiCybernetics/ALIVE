# ADR-0004 · 评测完整性：留出集、作废规则、防泄漏与外部评审

- 状态：Accepted
- 日期：2026-11-07
- 提出者：human
- 影响组件：A-EVAL-01，以及所有提示词、脚本库、人格文件
- 触及不变量：INV-10（扩展到开发过程本身）
- 关闭的待决事项：无

## 背景与证据

开发过程中出现过面向测试的修正：把测试场景及其标准答案写进系统提示，再用同样的场景评估效果；为一道失败的题补针对性的触发词；为让测试通过修改阈值（见 `docs/eval-log.md`）。这使当时报告的效果不可信。

## 决策

1. **留出集**：评测题目写在 `alive/eval/heldout_*.yaml`，在运行前写好，并附事先写定的期望。
2. **防泄漏**：`tests/eval/test_no_leak.py` 检查留出题的消息文本不出现在提示词、脚本库、话步目录与人格文件中，违反即测试失败。
3. **作废规则**：凡是因为某道留出题的失败而做的修改，那道题移入 `retired`，并写新题替换；修改必须是通用机制，不得针对具体题目的措辞。
4. **外部评审**：评审默认使用与生成不同家族的模型（本机 Codex CLI，`alive/eval/judge_codex.py`）；同源评审的结果需标注。
5. **如实记录**：所有对外报告过的评测都记入 `docs/eval-log.md`，包括失败与作废。

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| 只用单元测试 | 单元测试用模拟模型，无法评价话语质量 |
| 用同一模型评审 | 存在同源偏好 |
| 固定一套题反复调 | 必然过拟合 |

## 评估计划

不适用（本 ADR 规定评估本身）。

## 回滚方式

不适用。
