# ADR-0002 · 务实的事件溯源：经历为底账，派生状态为带引用的物化表

- 状态：Accepted
- 日期：2026-11-06
- 提出者：human（实现阶段）
- 影响组件：A-RT-01, A-RT-04, A-MEM-*, A-AFF-*, A-MOT-*, A-SOC-*
- 触及不变量：无（细化 ADR-0001）
- 关闭的待决事项：无

## 背景与证据

ADR-0001 要求所有状态都能从事件日志完全重建。实现时发现两类状态不适合严格重放：
- 连续动力学（情绪衰减、心境、需求、生理）每个心跳都在变化。若每次变化都写事件，日志会被心跳事件淹没，重放也慢。
- 由模型产生的派生物（记忆抽取、反思、表达学习）。重放时重新调用模型，结果不确定，成本也高。

## 决策

1. **经历类事件是唯一底账**：感知、思考、动作、结果、学习变更、治理决策全部写入事件日志，不可变。
2. **派生状态是物化表**：记忆、关系、意图、行为手册等由各子系统写入自己的表。每一行都带指回事件日志的证据引用。重建靠"保留表 + 可追溯"，而不是重放。
3. **连续状态用快照**：情感与需求定期写快照到键值表，并低频发出 `aff.snapshot` 事件。重启时从快照恢复，并按停机时长补算衰减。
4. **隐私删除例外**：被要求删除时，对日志中该人的消息内容做脱敏改写（见 ADR-0003）。

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| 严格事件溯源，所有变化都写事件 | 心跳级事件量大；含模型输出的派生物不可确定性重放 |
| 只存派生表，不存日志 | 失去审计与"为什么这么做"的因果链 |

## 评估计划

| 指标 | 期望 |
|---|---|
| 每条派生记录有证据引用的比例 | 100% |
| 重启恢复时间 | ≤ 60 秒 |
| 每日事件数 | 活跃个体 2k–20k |

## 回滚方式

不适用。
