# ADR-0005 · 非对话原则：以实体与行动为中心

- 状态：Accepted
- 日期：2026-11-07
- 提出者：human
- 影响组件：全部；主要是 A-SOC-*、A-CORE-*、A-REL-*，新增 A-WORLD-01/02、A-CORE-21
- 触及不变量：新增 INV-27、INV-28
- 关闭的待决事项：无

## 背景与证据

v0.1 的初版实现以会话为组织单位：
- 每个"通道:聊天编号"一份状态、一份历史、一次回复调用。
- 同一个人在不同平台被当作不同的对象。
- 收到一批消息就触发一次"要不要回复"的流程。

这与 ALIVE 作为"生活在世界里的个体"的定位矛盾。人不是按聊天窗口组织自己的认识，也不是对每条消息做一次应答。

## 决策

1. 新增实体注册表（`alive/world/`）。消息进入时第一步就解析为实体，传输层之上一律使用实体编号（INV-27）。同一个人跨平台的私聊合并为同一个场合，回复走最近活跃的路由。
2. 说话改为心智层选择的行动（INV-28）：
   - 注意力评估没有选中的感知，也交给心智层的工作空间，不调用模型。
   - 回复调用可以输出"晚点再说"，成为未来的工作空间事项。
   - 行动循环可以在任意场合自己开口：接上没回的话、补一句、转话题，或者不说。
   - 主动找人与在场合中开口共用同一条撰写与发送通路。
3. 私聊与群聊的差异只体现为"谁在场"：
   - 多人在场时一次只说一件事。
   - 发言占比显著超出合理份额时让出话头。
4. 前序文档中"对话、会话、线程"的表述按 22 号文档 §5 的映射重新理解。

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| 保留会话为单位，只增加跨通道合并 | 仍然让"会话"成为认知与行动的组织单位 |
| 完全重写社交层，由心智层接管注意力评估 | 风险与改动面过大；v0.1 先保留社交层的廉价评估作为注意过滤，由心智层做最终选择（OQ-54） |

## 评估计划

| 指标 | 期望 |
|---|---|
| 跨平台同一人的历史、关系、信任是否合一 | 是（tests/integration/test_entities.py） |
| 没被注意到的消息是否进入工作空间 | 是（tests/core/test_action.py） |
| 群聊发言占比 | 不再显著高于合理份额（生活模拟） |
| 自主开口次数与被回应率 | 记录于生活模拟报告 |

## 回滚方式

实体编号默认取首次见到的句柄字符串，因此关闭世界层解析即可回到"句柄即键"。行动通路的新增部分均可通过配置关闭：`mind.unprompted_min_gap_s` 设为极大值，或者让 `observe` 为空操作。

## 修订：2026-11-07 全仓审计

应负责人要求（"检查设计和系统中还有哪些违背了非面向对话原则，必须要改掉的改掉"），我们做了一次只读审计，逐项检查代码和文档里残留的以会话为单位的设计。结构性问题已全部修正，细节见 22 号文档 §4.5，新增 INV-29、INV-30：
- **说话路径。** 不由新消息触发的开口合并为一条通路，与回应共用撰写器。原先外联有自己的撰写器，本节"共用撰写器"的说法当时并不成立，现已落实。主动开口按实体计节奏，共享场合不再借用最后一个发言人的上限。
- **注意力。** 按人仲裁，同一个人在两个场合不会触发两份互不知情的发言。
- **拆句。** 按发言者判断一句话是否说完。
- **私聊应和。** 只看一眼，不强制开口；被 @ 时也不强制开口。
- **对话引擎。** 目标按人保存，按时间过期，不数轮次；话步效果由这个人自己之后在任何场合的反应来评估。
- **治理。** AI 身份声明按人记录；共享场合有自己的节奏上限；平台判断改走注册表路由。
- **关系与认知。** 关系、情绪对象、读心复盘一律以实体为准；发言倾向不再按平台设系数。
- **合并迁移。** 实体合并时迁移历史数据，落实 OQ-53 与 INV-27。
- **评估。** 模拟器里的人会拆句、不逐条回复、会主动开口；回复率改为描述性指标。

命名层面的残留（`thread_id`、`ReplyTask`、`dialogue` 包名）只是名字，不再承载会话语义，暂不改名。
