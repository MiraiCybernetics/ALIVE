# ADR-0003 · v0.1 实现中相对设计文档的偏差

- 状态：Accepted
- 日期：2026-11-07
- 提出者：implementation（三个子系统实现方与集成方）
- 影响组件：A-MEM-*、A-GROW-*、A-SOC-*、A-AFF-*、A-MOT-*、A-GOV-*
- 触及不变量：无（INV-14 由记忆系统以降级方式实现）

## 背景

v0.1 的实现由多方并行完成。实现中为了正确性、性能或可测试性，对设计做了若干调整。本 ADR 集中记录，便于后续逐项评估或回改。

## 决策：记录以下偏差

### 记忆（03）
1. **隐私删除是物理删除，不是按人加密销毁。** 删除范围包括：
   - 该人的记录及深度 3 以内的派生记录，连同全文索引、向量、实体与依赖行。
   - 事件日志中该人的消息内容，改写为脱敏占位。
   - 写入只含人物键哈希的墓碑事件。

   线程标识列未处理；旧页面可能在下次检查点前留在预写日志中。
2. 新增状态：`pending`（他人关于我的说法，待核实）、`superseded`（被更新的旧版本）；冲突用 `conflict_with` 列表而非状态表示。
3. 我自己说过的话只存为"我说过……"的情节记录，不作为事实。
4. 近重复合并分两步：极高相似度直接合并，较高相似度交给快速档模型确认语义相同后再确定性合并。原因是哈希向量无法区分"早上"与"晚上"这类差异。
5. 遗忘按线程与日期压缩弱情节；压缩会丢失超过 25% 时新增摘要而不是改写。

### 学习（06）
1. 版本表由触发器强制只追加；唯一例外是隐私脱敏。
2. 档位与文档不同：反思的提问步骤用中档、洞见步骤用深思档；学习阶段用中档。
3. 学习暂停时跳过反思、学习、验证、自我、做梦、训练，保留抽取、对账、遗忘、计划、预计算。
4. S3 证据转正条件：至少 3 条有益、至少 2 个不同对象与 2 个不同日期、有害不超过有益的三分之一。

### 社交（07）
1. 阅读者隔离实现为进程内的独立调用，提示中只有固定指令与网页正文，而不是独立进程。
2. 运行中消息：补充型在当前撰写完成后重写一次；纠正型立即取消并重写，最多两次。
3. 动态门控细节：一个防抖批次计为一轮；反馈因子限制在 0 到 1；被 @ 的强制回复在目标与实际两侧都按 0.91 计。
4. 私聊不经过话多程度与统计门控，总是交给认知核心。
5. 睡眠中私聊消息延后，每 10 分钟复查，紧急时立即回复。
6. Telegram 与 OneBot 默认群聊白名单、私聊配对；命令行与模拟通道开放。

### 情感、动机、治理（04、05、09）
1. 昼夜曲线使用余弦，使峰值落在配置的峰值时刻。
2. 心境强度分档阈值调整，使 ALMA 论文自己的例子仍为"略微放松"。
3. ALMA 的牵引与推动是两个分开的阶段，而不是相加。
4. 停机补算遵循作息，不累积无聊；超过 3 天的停机重置到基线，只模拟最后 2 天。
5. 危机模式在 48 小时无新信号后自动解除（可配置为只能手动解除）。
6. 主动外联被忽视 2 次后每天最多 1 次、间隔 24 小时；3 次后封锁 7 天。
7. 默认安静时段为 23:00–08:00 加上个体的睡眠窗口。
8. 首次接触即披露 AI 身份，默认开启，群聊也是。

### 集成
1. 主动外联结果的唯一上报方是社交层；认知核心只负责发起与传递计划标识。
2. 精力不足时降低思考档位的路由钩子由情感系统提供；认知核心只在情感系统不提供时补位。
3. 情绪调节优先使用情感系统自己的调节实现。

## 评估计划

逐项在生活模拟器与留出评估中观察；有明显负面影响的偏差，写新的 ADR 回改。

## 回滚方式

各项独立，可按项回改。
